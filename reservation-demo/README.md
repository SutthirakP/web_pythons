# จองสินค้าชิ้นสุดท้าย

มีรองเท้าเหลือคู่เดียว หลายคนกดพร้อมกัน — ต้องให้ได้แค่คนเดียว และถ้าจองแล้วไม่จ่ายภายใน 30 วินาทีต้องปล่อยให้คนอื่น

| Endpoint | หน้าที่ |
|---|---|
| `GET /product` | ดูสถานะ (`available` / `reserved` / `sold`) และเวลาจองที่เหลือ |
| `POST /reserve` | จอง → ได้ `reservation_token` ใช้ได้ 30 วินาที; มีคนจองอยู่ตอบ 409 |
| `POST /confirm` | ส่ง token มายืนยันการซื้อ; token ผิด 403, หมดเวลา 409 |

## สิ่งที่ได้เรียนรู้

- **Race condition:** สองคนเช็ค "ยังว่าง" พร้อมกันแล้วจองได้ทั้งคู่ → แก้ด้วย `asyncio.Lock` ให้ทีละคน
- **จองชั่วคราว:** เก็บเวลาหมดอายุด้วย `time.monotonic()` (ไม่เพี้ยนเมื่อเปลี่ยนเวลาเครื่อง) แล้วปล่อยของคืนเมื่อหมดเวลา
- **token สุ่มด้วย `secrets.token_urlsafe`** ให้เฉพาะคนที่จองยืนยันได้
- **Pydantic `Field(min_length=..., max_length=...)`** ตรวจ token ขาเข้า
